## CRM para Concessionaria


Este repositório será referente a construção de um sistema de gestão com cliente de uma concessionária. Toda a documentação estará disponível neste repositório, desde a construção do Product Backlog com o cliente, as dúvidas retiradas de cada reunião até as tecnologias utilizadas e arquitetura definida. <br> A idéia desde o principio será construir um sistema simples e intuitivo para todos os usuários da plataforma, nichando o público ao ramo de comércio automotivo.
